# Emergency Calls Data Analysis

## Overview
This project performs Exploratory Data Analysis (EDA) on an Emergency Calls dataset to identify patterns, trends, and key insights. Various visualization techniques were used to analyze emergency call frequency by category, month, day, and time.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Analysis
- Data Cleaning and Preprocessing
- Feature Engineering
- Emergency Type Analysis (EMS, Fire, Traffic)
- Monthly and Daily Call Trends
- Hourly Call Distribution
- Heatmaps and Clustermaps
- Data Visualization and Insight Generation

## Key Findings
- EMS calls were the most frequent emergency type.
- Call volumes varied significantly across months and weekdays.
- Peak emergency activity occurred during specific hours of the day.
- Heatmap analysis revealed recurring temporal patterns.
